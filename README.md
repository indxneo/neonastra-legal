# NeonAstra: privacy policy and support

The public pages for the NeonAstra iPhone game, served by GitHub Pages:

- Privacy Policy: https://indxneo.github.io/neonastra-legal/privacy/
- Support: https://indxneo.github.io/neonastra-legal/support/

These are the App Store's "Privacy Policy URL" and "Support URL", and the game links to both
from Settings.

**Don't edit the HTML here.** It's generated from the Markdown in the game's (private) repository,
`docs/legal/PRIVACY.md` and `docs/legal/SUPPORT.md`, by its `scripts/build_legal.py`:

```sh
# in the neonastra checkout, with this repository cloned next to it
python3 scripts/build_legal.py ../neonastra-legal
```

Then commit and push here; GitHub Pages publishes within a minute or two.
